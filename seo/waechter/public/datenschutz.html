Datenschutz

Entwurf: Die Angaben zum Verantwortlichen ergänzt hnvr.me vor dem Start. Die Beschreibung der Verarbeitung entspricht dem, was der Code tut.

Ohne Anmeldung

Die Werkzeuge rufen die Adresse ab, die Sie eingeben, und werten sie auf dem Server aus. Das Ergebnis geht an Ihren Browser und wird dort im lokalen Speicher abgelegt, damit Sie es später ins Konto übernehmen können. Auf dem Server wird es nicht gespeichert. Es wird kein Cookie gesetzt.

Eine eingefügte Mail wird nur für die Prüfung verarbeitet und danach verworfen, auch mit Konto.

Mit Konto

Gespeichert werden Ihre Mail-Adresse, Ihre Projekte (Domains), die Alarmadresse und die Ergebnisse Ihrer Prüfungen samt Verlauf. Für die Anmeldung setzt der Server ein Sitzungs-Cookie (HttpOnly, 30 Tage). Anmeldelinks und Sitzungen liegen nur als Prüfsumme vor. Unter Einstellungen können Sie alle Daten herunterladen und das Konto mit allen Daten löschen.

Wen der Server dafür anfragt

  • die geprüfte Website selbst
  • DNS-Server für Einträge, Mail-Einträge und Sperrlisten (Spamhaus, SpamCop, PSBL)
  • das RDAP-Verzeichnis der IANA und die RDAP-Server der Registrys für Registrierungsdaten
  • nur wenn auf dem Server eingerichtet: DataForSEO für Rankings und Backlinks, OpenAI, Google Gemini und Perplexity für KI-Fragen. Dabei geht nur das Keyword, die Domain oder die Frage dorthin.

Die Seiten laden keine Schriften, Skripte oder Bilder von fremden Servern.
